# WHOOP, Oura & Ultrahuman: features, logging, coaching & app design (state ~Nov 2026)

Method note: research done 2026-11-04 via WebSearch only. WebFetch was blocked for whoop.com, ouraring.com, 925studios.co and the5krunner.com (DNS not allowed in this session), so findings rely on search-result summaries; full-page verification was not possible. Many sources are company marketing (whoop.com, ouraring.com, ultrahuman.com) or affiliate/SEO review sites; these are flagged where relevant. Items marked "(older)" predate 2025.

## 1. Core scores/metrics and how each is presented

### Takeaway
All three are built around 3 daily "headline" scores (WHOOP: Sleep / Recovery / Strain; Oura: Readiness / Sleep / Activity; Ultrahuman: Sleep / Recovery / Movement Index) shown as dials or rings at the top of a home screen, with slower-moving "longevity" metrics (WHOOP Healthspan/WHOOP Age, Oura Cardiovascular Age/Resilience, Ultrahuman "Longevity" tab) pushed into a separate Health/My Health tab since the 2025-2026 redesigns. Add-on modules (WHOOP Advanced Labs, Oura Meals/Glucose, Ultrahuman Power Plugs & Metabolic Score) extend the core.

### Inferences
- For a personal app, the proven pattern is: 3 big daily scores (recovery/readiness, sleep, strain/activity) at top → "today" timeline of activities → longer-term trends in a separate tab. Every vendor converged on this in 2025-26.
- Readiness-style score = weighted contributors with a visible contributor list (Oura's model) is easier to reproduce transparently with Fitbit/Google Health data (HRV, RHR, skin temp, sleep) than WHOOP's opaque %.
- Ultrahuman's Movement Index (frequency of movement breaks, not only volume) is a cheap, distinctive idea that only needs step/intraday data.

### Gaps
- No primary-source detail found on Oura Cardiovascular Age computation (it is pulse-wave-velocity based per my background knowledge — unverified here), Oura Meals/glucose (Dexcom Stelo integration — background knowledge, unverified), or WHOOP Blood Pressure Insights methodology.
- WHOOP Plan / "My Plan" feature content not described in detail by any source found.
- Exact list of the 9 Healthspan inputs only partially known.

## 2. Manual / after-the-fact activity logging, activity types, effort & auto-detection

### Takeaway
All three auto-detect workouts and allow manual add/edit afterwards. Oura's manual flow (type + duration + intensity easy/moderate/hard, calories estimated from those three; edit up to 7 days back) is the clearest model for HR-less logging. WHOOP auto-recognises ~45 activity types and lets you relabel a generic "Activity"; whether manually added activities without band data earn Strain is contested in sources. No source confirmed named "yard work / housework / carpentry" activity types.

### Cited Findings
- WHOOP automatically recognises 45 activity types; anything else shows as a generic "Activity" you can assign afterwards; when unsure it shows the top three predicted activity types for the user to pick — [WHOOP: How WHOOP detects and labels your workouts](https://www.whoop.com/us/en/thelocker/how-whoop-detects-and-labels-your-workouts-activities/); [WHOOP support: Activity and sleep detection](https://support.whoop.com/s/article/Automatic-and-Manual-Activity-Detection)
- WHOOP manual add: choose activity type, set start and end time in a pop-up, save — [WHOOP support](https://support.whoop.com/s/article/Automatic-and-Manual-Activity-Detection)
- Strain from manual activities: WHOOP help article says Strain includes both auto-detected and manually logged activities; an older (~18-month-old) WHOOP Community thread says manual activities without wearing the band won't generate strain and approximating it "isn't possible yet" — [WHOOP support](https://support.whoop.com/hc/en-us/articles/360046006594-Why-Didn-t-My-Activity-Auto-Detect-); contradicted by [WHOOP Community thread](https://www.community.whoop.com/t/didnt-wear-whoop-during-activity-how-to-record-strain/329) (older)
- WHOOP Muscular Load estimated from activity type + duration even without HR; set/rep/weight logging improves it — [WHOOP: muscular load](https://www.whoop.com/us/en/thelocker/how-whoop-measures-muscular-load/)
- 2026: WHOOP reportedly added AI-generated Strength Trainer workouts and "more conversational logging" (log via Coach chat) — [Cybernews](https://cybernews.com/health-tech/whoop-review/); [strengthinsight blog](https://strengthinsight.app/blog/using-whoop-ai-coach/) (secondary/affiliate; not confirmed by primary WHOOP changelog). In-app workout builder praised — [TechRadar WHOOP MG review](https://www.techradar.com/health-fitness/fitness-trackers/whoop-mg-review)
- Oura manual add: from Today tab "+" menu → choose type, duration, intensity (easy / moderate / hard); default first choices Running, Walking, Cycling; can edit intensity afterwards; calories for manual activities computed from type + duration + intensity — [Oura support: Edit or manually add an activity](https://support.ouraring.com/hc/en-us/articles/360025577813-Edit-or-Manually-Add-an-Activity); [Oura support: Record a workout](https://support.ouraring.com/hc/en-us/articles/42821224955795-Record-a-Workout-with-Oura)
- Oura 2025: add/edit activities for the past seven days (previously current day only) — [Oura support / release notes via search summary](https://support.ouraring.com/hc/en-us/articles/360025577813-Edit-or-Manually-Add-an-Activity); older Wareable guide said current day only and that iOS allowed "Other" with a custom name — [Wareable (older)](https://www.wareable.com/wearable-tech/how-to-manually-add-workout-oura-smart-ring)
- Oura Automatic Activity Detection shows type, duration, intensity; workouts <10 min may not trigger — [Oura support: How Oura measures steps & activity](https://support.ouraring.com/hc/en-us/articles/360025576833-How-Oura-Measures-Steps-Activity)
- Oura says lower-intensity activities such as gardening count toward activity goals ("All Movement Counts") — [Oura blog: Activity score](https://ouraring.com/blog/activity-score/); [BusinessWire May 2025](https://www.businesswire.com/news/home/20250521864148/en/All-Movement-Counts-%C5%8CURA-Introduces-Enhanced-Activity-Features-and-Expands-Partner-Ecosystem)
- Ultrahuman Emerald (July 2026): rebuilt automatic workout detection with improved tagging; third-party devices can track selected workouts — [Android Authority](https://www.androidauthority.com/ultrahuman-emerald-update-3691001/)

### Inferences
- A sensible HR-less estimate for manual tasks (yard work, carpentry, housework): MET value per activity type (Compendium of Physical Activities) × body weight × duration, scaled by a user-chosen effort (easy/moderate/hard or RPE 1-10) — this mirrors Oura's type+duration+intensity approach. When Fitbit HR exists for the window, prefer HR-based strain (TRIMP / HR-zone minutes) and use MET only as fallback.
- WHOOP's "top-3 predicted types" chooser is a good UX pattern for confirming auto-detected Fitbit exercise sessions.

### Gaps
- Full WHOOP/Oura activity type lists not found; could not confirm whether "Yard Work", "Housework", "Manual Labor" or "Carpentry" are named types (WHOOP's list historically included several non-sport activities, but not verified here).
- WHOOP RPE input: not found in sources (no evidence WHOOP asks perceived exertion for normal activities).

## 3. Journal / behaviour-impact features

### Takeaway
WHOOP is the reference: a daily yes/no Journal (customisable behaviours), analysed by comparing Recovery on "yes" vs "no" days, gated at ≥5 yes and ≥5 no within 90 days, shown as % impact with significance labels, surfaced monthly (Monthly Performance Assessment) and since 2026 as "Behavior Trends". It is a simple correlation, which WHOOP itself admits can be confounded.

### Cited Findings
- WHOOP compares Recovery on days you logged a behaviour vs. days you didn't; shows which behaviours associate with higher/lower Recovery and by how much; compares yes vs no nights on RHR, HRV, sleep efficiency — [WHOOP: Journal & Behavior Impacts](https://www.whoop.com/us/en/thelocker/the-whoop-journal/); [WHOOP support: Recovery Impacts](https://support.whoop.com/s/article/Recovery-Insights?language=en_US)
- Threshold: ≥5 "yes" and ≥5 "no" within 90 days (one other WHOOP page says 10 entries over 30 days — conflict); only days with both a Journal entry and a Recovery score count — [WHOOP support: Journal overview](https://support.whoop.com/s/article/WHOOP-Journal-Overview?language=en_US); [WHOOP: Journal](https://www.whoop.com/us/en/thelocker/the-whoop-journal/)
- Effects grouped into categories such as significant / negligible positive or negative impact; WHOOP notes other behaviours may confound estimates — [WHOOP: Journal](https://www.whoop.com/us/en/thelocker/the-whoop-journal/)
- Third-party critique: "relatively simple correlation analysis", cannot establish causation or control confounders — [liveworksleep: WHOOP app features](https://liveworksleep.com/whoop-app-features/)
- Monthly Performance Assessment: released 1st of each month, found under Coaching tab, includes enhanced recovery analysis and suggests behaviours to try — [WHOOP: MPA enhanced recovery analysis](https://www.whoop.com/gb/en/thelocker/monthly-performance-assessment-now-features-enhanced-recovery-analysis/)
- 2026 "Behavior Trends": how specific habits influence recovery over time (same 5 yes / 5 no in 90 days rule) — [WHOOP 2026 What's New](https://www.whoop.com/us/en/thelocker/2026-whats-new/)

### Inferences
- Easy to replicate: daily checklist (alcohol, late meal, caffeine after 14:00, screen in bed, stretching, sauna, heavy manual work, etc.), then for each behaviour compute mean next-day recovery (or HRV/RHR deltas) yes vs no, show effect size with a confidence band, hide until n≥5 per group. Adding a simple regression controlling for previous-day strain would already beat WHOOP's method.

### Gaps
- Full default WHOOP Journal question list not retrieved (WHOOP has 100+ behaviours per background knowledge — unverified). No equivalent Oura or Ultrahuman behaviour-impact feature found in searches (Oura has Tags; Ultrahuman has none confirmed).

## 4. AI coaching (WHOOP Coach, Oura Advisor, Ultrahuman Jade)

### Takeaway
All three now ship an LLM coach grounded in the user's biometrics. WHOOP Coach added user-editable "My Memory" and Proactive Check-Ins (May 2026); Oura Advisor renders charts inline and (April 2026) uses Oura's own women's-health LLM; Ultrahuman's Jade got its own tab in July 2026. Main criticism: reactive rather than proactive, and limited independent testing.

### Cited Findings
- WHOOP Coach: conversational AI using HRV, RHR, skin temp, SpO2, respiratory rate, sleep stages, Strain, Recovery; useful for specific questions but criticised as reactive, not proactive — [agent-finder WHOOP Coach review](https://agent-finder.co/reviews/whoop-coach) (secondary)
- WHOOP "My Memory": central place to view, edit, delete the personal context used by the AI coach; can be turned off; plus "Proactive Check-Ins" (May 2026; earlier beta) — [WHOOP press release](https://www.whoop.com/us/en/press-center/whoop-expands-health-platform-with-on-demand-clinician-access-and-new-ai-features/); [Gadgets & Wearables](https://gadgetsandwearables.com/2026/05/08/whoop-memory/)
- Oct 2025 WHOOP home revamp moved the Coach button to the bottom-right corner — [the5krunner](https://the5krunner.com/2025/10/15/whoop-homescreen-gets-a-revamp/)
- Digital Trends: WHOOP plan flow "not very well automated so you spend a lot of time tapping the screen" — [Digital Trends WHOOP 5.0 review](https://www.digitaltrends.com/wearables/whoop-5-0-review/)
- Oura Advisor rolled out to all members March 31, 2025 — [BusinessWire](https://www.businesswire.com/news/home/20250331565896/en/Oura-Advisor-an-AI-powered-Personal-Health-Companion-Now-Rolling-Out-to-All-Oura-Members); opened via "+" button bottom-right → Advisor — [liveworksleep](https://liveworksleep.com/oura-app-features/)
- Advisor integrates sleep trends, activity changes and Meals dietary insights; can display user data as charts inline; April 2026 proprietary LLM for women's health; 83% of Oura Labs testers found answers reliable (company stat); users can name their Advisor — [Oura blog: Oura Advisor](https://ouraring.com/blog/oura-advisor/); [Oura blog: how to use Advisor](https://ouraring.com/blog/how-to-use-oura-advisor/); [Fortune](https://dc.fortune.com/2025/09/10/oura-ceo-interview-smart-ring-sales-doubled-wearables-brainstorm)
- Ultrahuman Jade AI gets dedicated tab connecting sleep, movement, recovery, glucose and blood tests; UltraSphere surfaces "Next Best Actions" — [Android Authority](https://www.androidauthority.com/ultrahuman-emerald-update-3691001/); [Stuff](https://www.stuff.tv/news/ultrahuman-rings-gets-a-huge-free-update-that-turn-them-from-smart-ring-into-a-life-coach/)

### Inferences
- For a solo build: a chat that can query your own DB and render small inline charts (Oura pattern) plus a short daily "next best action" card (Ultrahuman/WHOOP pattern) is more useful than free chat alone. A transparent, editable memory/profile (WHOOP My Memory) is a good trust pattern.

### Gaps
- No independent, rigorous evaluation of any of the three AI coaches found; Reddit sentiment could not be retrieved.

## 5. App design: visual language, layout, navigation, widgets, and reviewer sentiment

### Takeaway
WHOOP = dark, near-black UI where colour is reserved for data (recovery traffic-light green/yellow/red, Strain blue), big dials, progressive disclosure; criticised for density and repetition. Oura = calm "Nordic" design with muted gradients, soft curves, minimal 3-tab structure since Oct 2025, "one big thing" on Today. Ultrahuman = feature-dense, jargon-heavy, praised for clean sub-screens but "overwhelming" overall.

### Inferences
- Copyable design system for a personal web app: near-black background (#101518-ish), colour only for data; recovery as traffic light (≥66 green, 34-65 yellow, ≤33 red); strain in a single blue; 3 large circular dials at top; "score → contributors list → trend chart" drill-down (shared by all three); a single scrolling Today page plus a separate long-term Health page; keep notifications minimal (a praised WHOOP trait, a criticised Ultrahuman trait).
- Avoid the most common complaint (WHOOP, Ultrahuman): same data repeated across screens and unexplained jargon. Each metric should have one canonical home and a one-line plain-language explanation.
